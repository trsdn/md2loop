md2loop

Markdown ↔ Loop, one shortcut.

A lightweight macOS utility for seamless clipboard conversion between Markdown and Microsoft Loop.

Download for macOS View on GitHub →

Features

⌘⏎

One Shortcut

Auto-detects content type and converts — no menus, no fuss.

↔

Bidirectional

Markdown to Loop and Loop to Markdown, in either direction.

📋

Smart Clipboard

Sets HTML + RTF + plain text for maximum compatibility.

⚡

Lightweight

Native SwiftUI, no Electron, instant conversion.

📝

Full Markdown

Headings, tables, code, task lists, links, and more.

🔒

Private

Everything stays on your clipboard, no network access.

How It Works

📄

Copy

Copy Markdown or Loop content to your clipboard.

→
🔄

Convert

Press ⌘⏎ in md2loop to convert.

→
✅

Paste

Paste into your target app.
