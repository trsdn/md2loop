No configuration. No accounts. No internet. Just your clipboard.

⌘⏎

One shortcut

Auto-detects what's on your clipboard and does the right conversion. Markdown in? HTML out. Rich text in? Markdown out.

↔

Bidirectional

Markdown to Loop for pasting. Loop to Markdown for editing. Same app, same shortcut, both directions.

3×

Triple format

Sets HTML, RTF, and plain text on clipboard simultaneously. Maximum compatibility with every Microsoft app.

0ms

Instant

Native SwiftUI. No Electron, no web views, no runtime. Converts faster than you can lift your finger.

GFM

Full Markdown

Headings, bold, italic, strikethrough, lists, tables, code blocks, task lists, links, blockquotes, images.

∅

Zero network

Everything happens locally on your clipboard. No telemetry, no cloud, no analytics. Your text stays yours.

Three steps. One shortcut.

1

Copy

Copy Markdown text or Loop content to your clipboard.

2

Convert

Press ⌘⏎ in md2loop. It auto-detects and converts.

3

Paste

⌘V into Loop, or any Markdown editor. Done.
